# Hakuna Matata — יומן אימונים

אפליקציית ווב (PWA) לתיעוד אימוני כושר, בעברית ובכיוון RTL.

כל הנתונים נשמרים **מקומית בדפדפן** (`localStorage`) — אין שרת ואין בסיס נתונים.
אפשר לייצא ולשחזר גיבוי JSON מתוך מסך ההגדרות.

## שימוש

האתר מתארח ב-GitHub Pages:

**https://talshor-git.github.io/hakuna-matata-fitness/**

אפשר לפתוח אותו ישירות מהדפדפן, ובמובייל להוסיף למסך הבית כדי שיעבוד כמו אפליקציה.

## פיתוח מקומי

זה אתר סטטי בקובץ אחד. מספיק להגיש את התיקייה:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## קבצים

| קובץ | תיאור |
| --- | --- |
| `index.html` | כל האפליקציה (HTML + CSS + JavaScript בקובץ אחד) |
| `logo.png` | הלוגו של האתר (הסוריקטה עם המשקולות) |
| `favicon.png` | אייקון הלשונית |
| `apple-touch-icon.png` | אייקון למסך הבית באייפון |
