# Hakuna Matata — יומן אימונים

אפליקציית ווב (PWA) לתיעוד אימוני כושר, בעברית ובכיוון RTL.

כל הנתונים נשמרים **מקומית בדפדפן** (`localStorage`) — אין שרת ואין בסיס נתונים.
אפשר לייצא ולשחזר גיבוי JSON מתוך מסך ההגדרות.

## שימוש

האתר מתארח ב-GitHub Pages:

**https://talshor-git.github.io/hakuna-matata-fitness/**

אפשר לפתוח אותו ישירות מהדפדפן, ובמובייל להוסיף למסך הבית כדי שיעבוד כמו אפליקציה.

## פיתוח מקומי

זה אתר סטטי בקובץ אחד. מספיק להגיש את התיקייה:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## מאמן ה-AI

המאמן (במסך "תרגילים") עונה דרך **[OpenRouter](https://openrouter.ai)**.

במסך ההגדרות מזינים **מפתח API** מ-[openrouter.ai/keys](https://openrouter.ai/keys)
ובוחרים **עוצמת חשיבה**. ברירת המחדל היא המודל `deepseek/deepseek-v4.1-flash`,
שתומך בעוצמות: `ללא` / `נמוכה` / `גבוהה` / `מקסימלית` (ברירת מחדל: `גבוהה`).
המפתח נשמר רק ב-`localStorage` של הדפדפן ואינו נכלל בקובץ הגיבוי.

## מצב תצוגה

האפליקציה תומכת במצב **בהיר** ובמצב **כהה**. בהגדרות בוחרים בין
`לפי המערכת` / `בהיר` / `כהה` — ברירת המחדל היא לפי הגדרת המכשיר.
כל הצבעים מוגדרים כמשתני CSS בראש `index.html`, והערכה הכהה היא
בלוק `:root[data-theme="dark"]` שמחליף אותם.

## גרסה ועדכונים

בתחתית מסך **ההגדרות** מוצג מספר הגרסה וכפתור **"בדיקת עדכון גרסה"**.
הכפתור בודק מול גיטהאב אם פורסמה גרסה חדשה, ואם כן מרענן את האפליקציה
אוטומטית לגרסה האחרונה. מספר הגרסה מוגדר במשתנה `VERSION` בראש `index.html`.
